# Silente

Sitio web de Silente.

## Tecnología

- Next.js
- React
- TypeScript
- Tailwind CSS
- Motion
- Syne y Cormorant Garamond (SIL Open Font License 1.1)

## Desarrollo local

```bash
npm install
npm run dev
```
