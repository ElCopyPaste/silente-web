# Silente

Sitio web de Silente.

## Tecnología

- Next.js
- React
- TypeScript
- Tailwind CSS
- Motion
- Syne

## Tipografía

Syne es la tipografía vigente para el sistema completo de Silente, incluida la frase emocional.

Reckless fue reemplazada y no forma parte de la implementación vigente.

## Desarrollo local

```bash
npm install
npm run dev
```
