# Silente — decisiones de implementación

## Alcance actual

La Home se está construyendo a partir de la especificación técnica final entregada para Silente.

### No integrado técnicamente
- Pagos.
- WhatsApp.
- Video demo real.

Los destinos de esas acciones se incorporarán cuando estén definidos.

## Criterios visuales

- Mobile first.
- Fondo azul noche.
- Dorado como color de identidad y CTA.
- Syne como tipografía del sistema completo, incluida la frase emocional.
- La tipografía Reckless fue reemplazada y no forma parte de la implementación vigente.
- El logo real reemplazará el símbolo provisional.

## Criterio de desarrollo

No se inventan precios, URLs, contenidos de contratación ni recursos gráficos que no hayan sido definidos.
